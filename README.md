# Festronix 2026 Website

Open `index.html` locally or deploy this folder to Vercel.

- Homepage opens with the Festronix 2026 logo.
- Each event card opens a dedicated event page.
- Event pages use the isolated transparent event artwork.
- Pandora background is included locally.
- Registration button is a placeholder until the real registration form/QR is supplied.

Vercel: import/upload this folder as a static project. No backend or database is required for this version.
